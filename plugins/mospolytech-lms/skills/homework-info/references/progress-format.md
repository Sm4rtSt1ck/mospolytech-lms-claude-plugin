# Формат progress.json

## Корень

```json
{
  "updated": "2026-11-25",
  "semester": "2026-autumn",
  "subjects": { ... },
  "archive": { ... }
}
```

| Поле | Что это |
|---|---|
| `updated` | Дата последнего изменения файла, `ГГГГ-ММ-ДД`. Обновляется при любой правке – и агентом, и программой. |
| `semester` | Текущий семестр, например `2026-autumn` (см. [semesters.md](semesters.md)). |
| `subjects` | Предметы текущего семестра. Ключ – короткий латинский идентификатор предмета (`pir`, `philosophy`). |
| `archive` | Прошлые семестры. Появляется после первого перехода на новый семестр. |

## Предмет

```json
"pir": {
  "name": "Проектирование интеграционных решений",
  "aliases": ["ПИР", "интеграционные", "Иванов"],
  "teacher": "Иванов И.И.",
  "lms_course_id": null,
  "notes": "Лабы сдаются очно, очередь в теме «Очередь» чата группы.",
  "tasks": [ ... ]
}
```

| Поле | Что это |
|---|---|
| `name` | Полное название предмета, как в расписании. Показывается в программе. |
| `aliases` | Сокращения и прозвища: так предмет называют в чатах. Нужны для поиска в Telegram. |
| `teacher` | Преподаватели (`Фамилия И.О.`; если их несколько – кто ведёт что). |
| `lms_course_id` | id курса в LMS или `null`. Не угадывай по похожему названию: похожих курсов бывает несколько («Структурное проектирование» и «Проектирование интеграционных решений»). Сверь с названием предмета в расписании текущего семестра (ЛК), а если сомнения остались – спроси пользователя. Ставит скилл `lms-lab`, когда находит курс, или `homework-info`, когда ищет курс предмета. |
| `notes` | Всё о предмете в целом: где и когда занятия, правила зачёта, требования преподавателя, источники. |
| `tasks` | Записи предмета – и задачи, и события. |

Предмет `other` («Прочее (без привязки к предмету)») – для записей, которые не относятся ни к одному предмету (диплом, экзамены в целом, мероприятия кафедры). Если не ясно, к какому предмету относится запись, клади её в `other` и скажи об этом пользователю – не угадывай.

## Запись

```json
{
  "id": "lab-3",
  "title": "Лабораторная 3 – REST-интеграция",
  "type": "lab",
  "kind": "task",
  "deadline": "2026-12-20",
  "status": "in-progress",
  "done_at": null,
  "notes": "сдавать лично, по очереди в чате группы",
  "lms_assignment_id": 4567
}
```

| Поле | Значения | Что это |
|---|---|---|
| `id` | строка | Уникальный внутри предмета идентификатор: латиница, цифры, дефисы (`lab-3`, `kr-dialectic`). Не меняй у существующих записей. |
| `title` | строка | Что нужно сделать или что произойдёт. Коротко, но так, чтобы было понятно без `notes`. |
| `type` | код | Тип работы, см. [kinds-and-types.md](kinds-and-types.md). |
| `kind` | `task` / `event` | Задача или событие, см. [kinds-and-types.md](kinds-and-types.md). |
| `deadline` | `ГГГГ-ММ-ДД` / `null` | У задачи – срок сдачи, у события – дата события. `null`, если неизвестно. |
| `status` | `to-do` / `in-progress` / `done` / `cancelled` | См. [statuses.md](statuses.md). |
| `done_at` | `ГГГГ-ММ-ДД` / `null` | Когда запись выполнена. Заполняется только при `done`. |
| `notes` | строка | Подробности: требования, где лежат файлы, ссылки, источник информации и кто его написал, неясности. |
| `lms_assignment_id` | число | id задания в LMS, если запись соответствует заданию курса `lms_course_id`. Ставит скилл `lms-lab`, когда читает задание; у записей не из LMS этого поля нет. |

Поля пиши в этом порядке. Если пользователь добавил в программе своё поле (например, `priority`), сохраняй его.

## В notes указывай источник

Записи заполняются из личного кабинета, Telegram и LMS, и сведения там бывают разной надёжности. В `notes` пиши, откуда информация и кто это сказал:

- «ЛК, Петрова 19.11» – сообщение преподавателя, надёжно;
- «чат группы/Важное, Сидоров 14.11, со слов студентов» – пересказ, требует проверки;
- «со слов одногруппника (ЛС ТГ, 14.11)» – пересказ одного человека.

Неуверенные сведения не подавай как факт: так и пиши – «уточнить», «со слов».

## Даты

- Все даты – `ГГГГ-ММ-ДД` или `null`. Относительные даты («в пятницу», «через неделю») переводи в абсолютные при записи.
- Если известно только «в ноябре», ставь последний день месяца и пиши в `notes`, что точной даты нет.
