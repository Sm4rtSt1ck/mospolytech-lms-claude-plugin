# Оформление отчёта в Typst по ГОСТ

Шаблон — локальный пакет `${CLAUDE_PLUGIN_ROOT}/templates/typst/local/mospolytech-gost/0.1.0/` (`styles.typ` — стиль, `titlepage.typ` — титульник). Сам шаблон не правь ради одного отчёта; если правило в нём неверно для всех работ — скажи пользователю.

Где методичка курса расходится с ГОСТ или этим файлом, приоритет у методички курса. Где её нет — у этого файла.

## Каркас лабораторной / практической

```typst
#import "@local/mospolytech-gost:0.1.0": *
#show: gost

#make_title(
  course: "Проектирование информационных ресурсов", // полное название дисциплины, как в LMS
  topic: "Анализ надёжности и наблюдаемости",       // тема работы; "" — строка «по теме» не выводится
  lab_number: 2,                                      // номер работы: 2, "7.2"; none — без номера
  student_group: "123-456",
  student_name: "Иванов И. И.",
  teachers: "Доцент кафедры ИКТ - Иванов И.И.",       // "должность - ФИО"; несколько — через ", "; none — без «Проверил»
  // work_type: "Практическая работа",                // по умолчанию «Лабораторная работа»
)

= Анализ требований
...
```

Откуда брать значения титульника:
- `student_name` — `student.short_name` из `profile.yaml` рабочей папки, `student_group` — `student.group`;
- `teachers` — `courses.<course_id>.teachers` из `profile.yaml`; значение `none` там означает «не указывать» — передай `teachers: none` и не спрашивай снова. Если в профиле пусто — из `context.md` курса (должность и ФИО), иначе спроси пользователя и сохрани ответ в `profile.yaml` (`none`, если преподавателя указывать не нужно);
- `work_type` — как работа названа в курсе: «Лабораторная работа», «Практическая работа», «Домашняя работа», «Реферат»; по умолчанию лабораторная;
- `lab_number` — номер, если он есть в названии работы в LMS («Практика 3» → 3); у ненумерованных работ — `none`;
- `course` — полное название дисциплины из LMS без служебных пометок вроде «(Осень)», номеров групп и годов;
- `topic` — тема из названия или описания задания;
- `year` по умолчанию текущий; передавай явно, только если работа за прошлый год.

Свой титульник в отчёте не верстай — для лабораторных, практических, домашних работ и рефератов хватает параметров `make_title`. Курсовую, ВКР и отчёт по практике шаблон не покрывает (там другие обязательные поля) — для них сначала спроси пользователя, как оформить титульник.

## Структура

- По умолчанию свободная, по заданиям: каждое задание — раздел `=`. Цель, введение, заключение, содержание и список источников — только если их требует курс или работа большая.
- Раздел `=` называй по содержанию задания: `= Расчёт показателей надёжности` → «1 РАСЧЁТ ПОКАЗАТЕЛЕЙ НАДЁЖНОСТИ». Не пиши `= Задание 1` — выйдет «1 ЗАДАНИЕ 1».
- Если задание вообще без названия, сформулируй короткое по сути («= Настройка мониторинга»), а исходную формулировку задания процитируй первым абзацем раздела.
- Внутри раздела — `== Подраздел` (1.1), `=== Пункт` (1.1.1). Не ставь `==` под ненумерованный `#head[...]`: получится «0.1».
- Каждый `=` начинается с новой страницы. Если задания короткие и не должны идти с новых страниц, сделай один `=` на всю работу (`= Выполнение работы`), а задания — `==` внутри.
- Ненумерованные структурные элементы («Введение», «Заключение», «Список источников» и др. из `_STRUCTURAL` в `styles.typ`) пишутся как `= Введение` или `#head[Введение]`.
- Нумерация страниц: считается с титульника, печатается со 2-й страницы. Если есть `#contents()` — печатается начиная со страницы содержания.

## Файлы отчёта

Всё, что использует отчёт, лежит в его папке; компиляция идёт с `--root` = папка отчёта.

- Картинки — в `assets/` рядом с `report.typ`. Шаблон — пакет, поэтому путь из документа передаётся через `path()`:
  ```typst
  #img(path("assets/architecture.png"), [Архитектура системы], width: 80%) <fig-arch>
  ```
  Строка вместо `path(...)` вызовет ошибку с подсказкой. Обычный `image("assets/x.png")` внутри своего `figure(...)` работает и со строкой.
- Источники — `refs.bib` рядом с отчётом и `#references(path("refs.bib"))`, либо ручной список `#sources([...], [...])`.
- Код для листингов — в `src/`; в отчёт вставляй как `figure(raw(read("src/main.py"), lang: "python", block: true), caption: [...])` или фрагментом ```` ```python ```` внутри `figure`.
- Скриншоты, которых у тебя нет, не рисуй и не подделывай: поставь в текст пометку `// TODO скриншот: <что снять>` и сообщи пользователю.

## Функции шаблона

| Что | Как |
|---|---|
| Рисунок | `#img(path("assets/x.png"), [Название], width: 80%) <fig-x>` |
| Таблица | `#tbl([Название], table(columns: 3, table.header([A], [B], [C]), ...)) <tab-x>` — шапка через `table.header`, тогда при переносе повторится и появится «Продолжение таблицы N» |
| Листинг | `#figure(```python ... ```, caption: [Название]) <lst-x>` |
| Формула | `$ P(t) = e^(-lambda t) $ <eq-p>`, после — `#explain[$lambda$ — интенсивность отказов, 1/ч.]` |
| Структурный элемент | `#head[Введение]`; без включения в содержание — `#head(outlined: false)[Аннотация]` |
| Содержание | `#contents()` |
| Пункт без заголовка | `#punkt[Текст пункта…]` |
| Приложения | `#show: appendices`, затем `#appendix(status: "справочное", label: <app-a>)[Название]` |
| Источники | `#references(path("refs.bib"))` или `#sources([...], [...])`; электронный ресурс — `#elsource([Название], "https://…", "28.10.2026")` |
| Сокращения | `#abbreviations(("ИС", [информационная система]), ...)` |
| Нумерация в пределах раздела | `#show: gost.with(by-section: true)` — 1.1, 1.2 вместо 1, 2 |

Ссылки: `@label` даёт только номер. Слово в нужном падеже — в скобках: «на @fig-x[рисунке]» → «на рисунке 1», «по @eq-p[формуле]» → «по формуле (1)», «в @tab-x[таблице]». На каждый рисунок, таблицу, листинг и приложение должна быть ссылка в тексте до него.

Списки: `-` — тире; `+` — «1.» на первом уровне, «а)» на втором, «1)» на третьем.

## Правила текста (шаблон их не проверяет — следи сам)

- Пунктуация списков: список «1.» — пункты с прописной, в конце точка; остальные — со строчной, в конце «;», в конце списка «.»; вложенные — со строчной, в конце «,».
- Полужирный — только в заголовках. Курсив — для терминов при первом упоминании.
- Подписи без точки в конце; тире в подписях ставит шаблон.
- Источники нумеруются в порядке первого упоминания: [1], [1, с. 5].
- Текст — от первого лица множественного числа или безлично («выполнено», «рассчитаем»), без разговорных оборотов.

## Что уже реализовано в стиле (не дублируй и не ломай)

- А4; поля 30/15/20/20 мм; Times New Roman 14 пт; интервал 1,5; абзацный отступ 1,25 см; по ширине; без переносов; без интервалов между абзацами.
- Заголовки глав по центру, прописными, полужирные, с новой страницы, без точки; подразделы и пункты с абзацного отступа. Пустая строка только перед подразделом после текста.
- «Рисунок N – Название» под рисунком по центру; «Таблица N – Название» над таблицей слева; таблицы 12 пт, одинарный интервал; «Продолжение таблицы N».
- Формулы по центру, свободные строки сверху и снизу, номер «(N)» справа.
- Приложения «ПРИЛОЖЕНИЕ А» со статусом; буквы Ё, З, Й, О, Ч, Ъ, Ы, Ь пропускаются; нумерация внутри «А.1».
- Подписи и номера заголовков ведут к первому упоминанию; содержание — уровни 1–2 через отточие.

Стандарты, на которые опирается стиль: ГОСТ 7.32-2017 (отчёт), ГОСТ 2.105 (текстовые документы), ГОСТ 9327 (формат), ГОСТ Р 7.0.5-2008 и ГОСТ 7.1-2003 (библиография). Для ТЗ, ПМИ и схем алгоритмов, если работа их требует: ГОСТ 19.201-78, ГОСТ 19.301-79, ГОСТ 19.701-90.

## Сборка и проверка

Команда `typst-gost` из плагина есть в PATH инструмента Bash (в PowerShell — `typst-gost.ps1`):

```
typst-gost <папка>/report.typ <папка>/<Имя файла>.pdf
```

Обёртка подключает шаблон, шрифты из `fonts/` рабочей папки (и шрифты Windows в WSL), ставит `--root` на папку отчёта. Если команды нет в PATH — `"${CLAUDE_PLUGIN_ROOT}/bin/typst-gost"`.

1. Собирай, пока нет ни ошибок, ни предупреждений. Предупреждение о ненайденном шрифте — не игнорируй: без Times New Roman отчёт не по ГОСТ: попроси пользователя положить шрифты (Times New Roman, Courier New, Cambria Math) в `fonts/` рабочей папки или установить их в систему.
2. Визуальная проверка — PNG во временную папку, не рядом с отчётом (готовый PDF можно смотреть и через Read с `pages`, если установлен poppler):
   `typst-gost <папка>/report.typ <tmp>/page-{p}.png --ppi 60 --pages 1-3`
   Посмотри титульник, первую страницу текста и страницы с таблицами/рисунками; для длинных отчётов — ещё конец.
3. Проверь: ссылки на все рисунки/таблицы есть, нет пустых страниц, таблицы не вылезают за поля, листинги помещаются на страницу (длинный код дели на несколько листингов или выноси в приложение).
